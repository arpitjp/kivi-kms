# @kivi/shared-types

Shared TypeScript interfaces and types used across all Kivi packages.

Defines the contracts for Markdown AST nodes, search results, theme options, editor configuration, and vault file metadata — ensuring type consistency between the parser, serializer, editor, and vault.

## Usage

```ts
import type { SearchOptions, SearchResult, KiviTheme } from '@kivi/shared-types';
```
